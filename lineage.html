Format is auto-detected:
  • CSV / TSV with columns table,depends_on (header optional; source,target / from,to / parent,child / upstream,downstream headers are recognised). Multiple deps in one cell can be separated by ; or |.
  • Arrows: one per line, raw.orders -> stg_orders -> fct_orders (data flows left to right).
  • JSON: {"table": ["dep1","dep2"]}, [{"table":"x","depends_on":[…]}], [{"source":"a","target":"b"}], or a dbt manifest.json.
  • SQL: CREATE TABLE/VIEW … AS SELECT, INSERT INTO … SELECT, MERGE INTO … USING. Reads FROM/JOIN and skips CTEs. dbt ref()/source() work too; for model files the file name is the table.
